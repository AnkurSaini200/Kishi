# Why JWT?

We use JWT for stateless API authentication.

The backend validates the token on protected requests.

JWT is used for authentication, not vault encryption.


# Why client-side encryption?

The vault contains highly sensitive information.

We don't want the database to contain plaintext credentials.

Therefore sensitive vault data is encrypted before being
sent to the backend.



# Why PostgreSQL?

Kishi has relational data:

User
  └── Vault Entries

PostgreSQL provides relational integrity and works well
with Spring Data JPA.
